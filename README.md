# Habit Tracker

A small web app for tracking daily habits. Add a habit, mark it done for today, and see how many days in a row you have kept it.

**Live demo:**  https://danyar2207.github.io/danyar-temirbaev.github.io/

## Features

- Add and delete habits
- Mark a habit as done for today
- Streak counter that updates automatically
- Data is saved in the browser, so it stays after you reload the page

## Tech

HTML, CSS, and vanilla JavaScript. No frameworks and no build step.

## Run locally

Open `index.html` in any browser.
